A // Templates

Minimal, working examples. Clone the repo, change the IP, and run. If the template runs, your setup is good and any failure in a real project is the project, not the environment.

i
Verify before you build. Always confirm the Python template runs end-to-end before adding camera capture, AI inference, or a custom toolpath. It rules out 90 % of "why isn't this working" before you write a single new line.

C // Contribute a project

If you worked on something in the lab — add it here. Future students will thank you.

  1. Create a folder under Projects/ named after your task (no spaces — use underscores).
  2. Add a README.md with: what it does · install · how to run · controls · safety notes specific to your setup.
  3. Strip secrets. No passwords, no real IPs, no auth tokens. Use placeholders.
  4. Open a PR against the GitHub repo. Add an entry to data.js so it appears on this page.
